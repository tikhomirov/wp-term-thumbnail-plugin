# Changelog

## 1.0.4 — 2026-09-17

### Fixed
- PHP 8 fatal при просмотре списка терминов без миниатюры (`wp_get_attachment_image_src()[0]` на `false`).
- PHP 8 fatal при редактировании термина без изображения.
- Безопасная работа `get_current_screen()` в админке.
- Корректное определение `term_id` в `get_term_thumbnail()` вне архивов таксономий.
- Ссылка «Настройки» на странице плагинов (`strpos` при совпадении с начала строки).
